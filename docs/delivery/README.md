# Delivery

Read [sprint-plan.md](sprint-plan.md). That is the plan: nine sprints, what each one delivers,
who leads it. Five minutes, and you know where the project is.

[sprint-detail.md](sprint-detail.md) is reference material — the detailed backlog of
individual pieces of work, with the acceptance criteria behind them. It is numbered internally
and it is not part of the reading path. Open it when you want the detail on one specific
thing.
