# Decision Records

One file per decision that is expensive to reverse: `NNN-short-title.md`, numbered in order.

Record a decision here when reversing it would mean rewriting code, migrating data, or
renegotiating an interface other systems depend on. Day-to-day choices belong in the pull
request that makes them.

Each record answers four questions: what we decided, why, what we gave up, and what would
make us revisit it.
