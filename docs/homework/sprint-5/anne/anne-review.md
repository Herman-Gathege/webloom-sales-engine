# Anne — Sprint 5 Seller Review

**Verdict:** Revise. The campaign flow could not be tested because there is no way to get
leads into the system.

## What I found

- **No leads in the system.** Campaign List, Preview and Drafts cannot be tested without them.
- **No way to add a lead by hand.** A seller cannot enter one test business.
- **The Import screen has no template.** It does not say which columns are expected and offers
  no sample CSV to download, so a seller cannot prepare a file that will import.
- **Fix:** add a downloadable CSV template with example rows to the Import screen.

## Sellers building campaigns (to confirm once leads exist)

- **Drafts cannot be redone.** Warn before generating, and allow a wrong campaign to be
  archived.
- **Skip reasons must be in plain words.** For example "Landline only", "Opted out", with a
  count per reason.
- **Targeting must filter by website and social presence,** or the social-only copy cannot be
  used safely.
- **Label drafts "Not sent".** Nobody should think a message has gone out.
- **Show SMS length and segment count** on every draft, because each extra segment costs more.
- **Explain the "goal" field.** Sellers need to know what to write in it.

## Credibility with the businesses we contact

- **"No website" must still be true.** Show the research date and re-check older leads.
- **Name the sender.** Name Webloom and a real person, and use a registered SMS sender ID.
- **Someone must own opt-outs.** Replies are not captured automatically, so one person
  checks them daily.
- **Prices must be exact.** Confirm whether Starter Website is "from KES 40,000" or exactly
  KES 40,000.
- **Business names need a human check** before approval (capital letters, branch names).
- **No messages at night or on Sundays** (for Sprint 6).

## Next step

Re-run this review once leads can be imported or added.
